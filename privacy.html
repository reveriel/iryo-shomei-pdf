医療証明書類 PDF 生成ツール（以下「本ツール」といいます）は、利用される方の情報を適切に取り扱うことを重要な責務と考えています。 本プライバシーポリシー（以下「本ポリシー」といいます）は、本ツールにおける利用者情報の取扱い方針を定めるものです。

1. 本ツールに入力された情報の取扱い（重要）

本ツールは、入力された内容を当方のサーバーへ送信しません。医療機関名、患者氏名、生年月日、傷病名、診療内容、金額その他ご入力いただいた一切の情報は、 お使いの端末のブラウザ内だけで処理され、PDF・印刷の生成もすべて端末内で完結します。

当方が入力内容を保存・収集・閲覧することはありません。ページを閉じるか再読み込みすると、入力内容は破棄されます。 本ツールには入力内容を保存する機能（アカウント・クラウド保存等）はありません。

2. 取得する情報

本ツールは、利用者から次の情報を取得することがあります。

  • アクセス解析により自動的に取得される技術情報（閲覧ページ、参照元、閲覧日時、ブラウザ種別、端末種別、国・地域、IP アドレス等）
  • お問い合わせ・フィードバックとして利用者が任意に送信した内容（本文、および利用者が任意で記入した連絡先）

本ツールの入力フォームに記載された医療情報・個人情報は、前項のとおり取得しません。

3. アクセス解析ツールについて

本ツールは、利用状況の把握と改善のため Cloudflare Web Analytics（提供：Cloudflare, Inc.）を利用しています。 同サービスはCookie を使用せず、個人を特定しない統計情報としてアクセス状況を計測する方式を採用しています。 取得される情報は、ページビュー、参照元、閲覧環境等の集計値であり、特定の個人を識別するものではありません。

同サービスにおける情報の取扱いの詳細は、Cloudflare, Inc. のプライバシーポリシーをご確認ください。 なお、ブラウザの設定により JavaScript を無効化した場合、本ツールの一部機能（プレビュー・PDF 生成等）は動作しません。

4. Cookie（クッキー）の利用

本ツール自体は、利用者を追跡する目的の Cookie を発行しません。Cookie を利用した広告配信・行動ターゲティングも行いません。 ページの表示に外部のフォント配信サービスを利用しているため、同サービス提供者が技術的な情報を取得する場合があります（次項）。

5. 外部サービスの利用

本ツールの表示および運営のため、次の外部サービスを利用しています。各サービスにおいては、それぞれの提供者のプライバシーポリシーが適用されます。

  • Google Fonts（提供：Google LLC）— 文字表示のため。フォント取得時に利用者の IP アドレス等の技術情報が同社に送信される場合があります。
  • Cloudflare Web Analytics（提供：Cloudflare, Inc.）— 前項のとおり。
  • Google フォーム（提供：Google LLC）— お問い合わせ・フィードバックの受付に使用しています。
  • GitHub Pages 等の静的ホスティング — 本サイトの配信のため。アクセスログとして IP アドレス等が記録される場合があります。

6. お問い合わせ・フィードバックで送信された情報

本ツールのフィードバックボタンおよびお問い合わせ窓口は Google フォームで運用しています。 送信いただいた内容は、本ツールの不具合修正・改善、およびご質問への回答の目的にのみ利用します。 この送信は利用者が任意に行うものであり、ツールの利用にあたって必須ではありません。 入力フォームに入力中の内容が、自動的に送信されることはありません。

7. 利用目的

  1. 本ツールの提供、維持、不具合の修正および改善のため
  2. お問い合わせ・フィードバックへの対応のため
  3. 本ポリシーまたは利用条件に違反する行為への対応のため
  4. 法令に基づく対応のため

8. 第三者への提供

当方は、次の場合を除き、取得した情報を第三者に提供しません。

  1. 利用者本人の同意がある場合
  2. 法令に基づく開示が必要な場合
  3. 人の生命、身体または財産の保護のために必要があり、本人の同意を得ることが困難な場合
  4. 本ツールの運営に必要な範囲で業務委託先に取り扱いを委託する場合（この場合、当方は委託先を適切に監督します）

当方は、取得した情報の漏えい、滅失または毀損の防止その他の安全管理のために必要かつ適切な措置を講じるよう努めます。 本サイトは HTTPS（TLS）により通信を暗号化して配信されます。

1. 关于输入内容（重要）

本工具不会把您输入的内容发送到服务器。医疗机构名称、患者姓名、出生日期、病名、诊疗内容、金额等一切输入信息， 仅在使用者本人的浏览器内处理，PDF 生成与打印也在本地完成。我们不会保存、收集或查看您的输入内容。 关闭或刷新页面后，输入内容即被丢弃；本工具不提供账号或云端保存功能。

2. 我们获取的信息

  • 访问分析自动取得的技术信息（浏览页面、来源、时间、浏览器与设备类型、国家/地区、IP 地址等）
  • 您主动通过反馈表提交的内容（正文，以及您自愿填写的联系方式）

表单中填写的医疗与个人信息，如第 1 条所述，我们不予获取。

3. 访问分析

本工具使用 Cloudflare Web Analytics（Cloudflare, Inc. 提供）统计访问情况。该服务不使用 Cookie， 以不识别个人身份的统计方式计量，取得的是页面浏览、来源、浏览环境等汇总值，不能识别特定个人。

4. Cookie 的使用

本工具本身不发放用于追踪使用者的 Cookie，也不进行基于 Cookie 的广告投放或行为定向。

5. 使用的第三方服务

  • Google Fonts（Google LLC）— 用于字体显示，获取字体时您的 IP 等技术信息可能被发送至该公司。
  • Cloudflare Web Analytics（Cloudflare, Inc.）— 同上。
  • Google 表单（Google LLC）— 用于接收反馈与咨询。
  • 静态托管服务（GitHub Pages 等）— 用于站点分发，访问日志中可能记录 IP 地址等。

6. 反馈与咨询信息

反馈入口通过 Google 表单运营。您提交的内容仅用于修复缺陷、改进工具以及答复您的提问。 提交完全出于自愿，并非使用本工具的前提。表单中正在输入的内容不会被自动发送。

7. 利用目的

  1. 提供、维护、修复与改进本工具
  2. 答复咨询与反馈
  3. 处理违反本政策或使用条款的行为
  4. 依法应对

8. 第三方提供

除下列情形外，我们不会向第三方提供所获取的信息：本人同意；依法须披露；为保护生命、身体或财产且难以取得本人同意；在运营必要范围内委托受托方处理（此时我们会妥善监督受托方）。

我们努力采取必要且适当的措施，防止信息泄露、灭失或毁损。本站通过 HTTPS（TLS）加密传输。

您可以就我们所持有的您的信息要求查阅、订正、追加或删除。请在下方窗口联系我们，我们将在确认本人身份后，依法在合理期间内处理。
